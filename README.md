# 🌤️ Weather Condition Prediction App

An interactive Machine Learning web application that predicts weather conditions using an Ensemble Stacking Classifier model.

 **[Click Here to Try the Live Application!](https://rw3xgn2tugvahtautvdfpr.streamlit.app/)**

---

## 📌 Project Overview
This project builds an end-to-end Machine Learning pipeline to predict rainfall outcomes. 
The application takes user inputs (temperature, humidity, pressure, etc.) and delivers real-time weather predictions.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Machine Learning:** Scikit-Learn, XGBoost, Stacking Classifier
* **Web Framework:** Streamlit
* **Deployment:** Streamlit Community Cloud, GitHub

## ⚙️ Model Architecture
* **Base Models:** Random Forest, XGBoost, LinearSVC
* **Meta Model:** Logistic Regression
* **Preprocessing:** Pipeline with `SimpleImputer`, `StandardScaler`, and `OneHotEncoder`
